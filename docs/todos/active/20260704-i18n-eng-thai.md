## 1. Goal

Fix display logic for API `i18n` fields on tags/circles/voice actors: currently hardcoded to prefer `zh-cn`, so English devices still show Chinese; `en-us` model exists but is unused for display; `th-th` is missing. Unify name resolution by system `Locale` and add Thai model fields.

## 2. Scope

**In scope:**
- Add `ThTh` model and `I18n.thTh` field
- Centralized `I18nNameResolver` utility
- Update tag display/browse/search to use resolver
- Circle and voice-actor browse lists use resolver
- Unit tests + release APK build

**Out of scope:**
- UI copy (`Strings`) localization
- User-selectable app language setting

## 3. Acceptance

- [x] English system locale prefers `en-us` tag names
- [x] Thai system locale prefers `th-th` (shows when present, otherwise fallback chain)
- [x] `I18n` model includes `th-th` and build_runner artifacts generated
- [x] `flutter analyze` passes with no new warnings
- [x] Related unit tests pass
- [x] Release APK build succeeds
