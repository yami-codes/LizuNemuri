# API i18n 显示修复：英文/泰文 + 按系统语言解析

- **创建时间**：2026-07-04
- **负责人**：cursor-agent
- **状态**：active
- **关联 Issue / PR**：

---

## 1. 目标（Goal）

修复标签/社团/声优等 API `i18n` 字段的显示逻辑：当前硬编码优先 `zh-cn`，英文设备仍显示中文；`en-us` 模型存在但未用于展示；缺少 `th-th`。统一按系统 `Locale` 解析名称并补齐泰文模型字段。

## 2. 范围（Scope）

**包含：**
- 新增 `ThTh` 模型与 `I18n.thTh` 字段
- 集中式 `I18nNameResolver` 工具
- 更新标签展示/浏览/搜索处使用 resolver
- 社团、声优浏览列表同步使用 resolver
- 单元测试 + release APK 构建

**不包含：**
- UI 文案（`Strings`）多语言化
- 用户可选应用语言设置

## 3. 验收标准（Acceptance）

- [x] 英文系统语言下标签优先显示 `en-us` 名称
- [x] 泰文系统语言下优先显示 `th-th`（有则显示，无则按 fallback）
- [x] `I18n` 模型含 `th-th` 且 build_runner 产物已生成
- [x] `flutter analyze` 通过，无新增 warning
- [x] 相关单元测试通过
- [x] release APK 构建成功

## 4. 拆解步骤（Steps）

- [x] **Step 1**：新增 `th_th.dart`，扩展 `i18n.dart`，运行 build_runner
- [x] **Step 2**：实现 `I18nNameResolver` + 单元测试
- [x] **Step 3**：替换 `work_tags_panel` / `work_info` / `tags_screen` / viewmodels
- [x] **Step 4**：`flutter analyze` + `flutter test` + `flutter build apk --release`

## 5. 风险与回滚（Risks）

- **风险**：API 若暂无 `th-th` 字段，泰文环境会 fallback 到 en/zh/ja，行为仍优于旧逻辑
- **回滚方案**：revert 本分支 commit

## 6. 备注 / 决策记录

- 搜索仍用 API 原始 `name` 作为 `$tag:` 查询键，仅展示名本地化
